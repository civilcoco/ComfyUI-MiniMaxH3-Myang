# Security policy

## Supported version

Security fixes are applied to the latest tagged release.

## Reporting

Use GitHub's private vulnerability reporting feature after it is enabled for
the repository. If that feature is not visible, open a minimal issue asking the
maintainer for a private contact channel; do not include credentials, private
media, exploit code or sensitive machine details in the public issue.

Never attach a complete ComfyUI workflow before checking it for API keys,
tokens, absolute paths, filenames that reveal personal information and embedded
input metadata.
