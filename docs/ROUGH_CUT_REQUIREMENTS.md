# 粗剪时间轴与智能创作助手需求

## 范围

第一阶段在导演台增加本地粗剪工作区，让已有素材、导演台生成模式和 I/O 插入形成闭环。它不是要在节点卡片内复制一套 Premiere，而是先解决素材组织、帧级摆放、区间生成、覆盖写入和前后镜头衔接。

智能图片生成、图片编辑和自动路由属于后续实验阶段；首版不得让 LLM 任意构造或执行 ComfyUI 工作流。

## 功能需求

| ID | 需求 | 验收标准 |
|---|---|---|
| RC-001 | 粗剪功能必须可选 | 关闭时不改变现有导演台构图、时长、模型和输出；开启后才读取粗剪工程。 |
| RC-002 | 支持多个本地素材文件夹 | 用户可登记、切换和移除多个文件夹；移除登记不删除磁盘文件。 |
| RC-003 | 素材百宝箱支持视频、图片和音频 | 支持的文件可搜索、预览并拖入相应轨道；不支持的扩展名不显示。 |
| RC-004 | 时间轴统一使用整数帧 | 工程保存 fps、时间线入出帧和素材入出帧；UI 可显示秒和时间码，但不得用浮点秒作为权威位置。 |
| RC-005 | 支持 I/O 区间 | 可用播放头设置 I、O，也可直接输入时间；O 必须晚于 I。 |
| RC-006 | 生成结果覆盖选区 | 选区内旧片段被覆盖；跨过 I/O 的旧片段在边界处拆分；选区之外的素材不移动，不做 ripple edit。 |
| RC-007 | 生成时长服从 I/O | 导演台把 I/O 时长交给现有生成模式；H3 网格向上取整产生的多余帧在保存前精确裁掉；不足时只允许末帧补齐并明确记录。 |
| RC-008 | 支持三种入点/出点约束 | 每侧可独立选择关闭、单帧关键图或 MotionContext 窗口。单帧模式可与 Ref2VA 素材条件组合。 |
| RC-009 | 入点 MotionContext | 从 I 前读取与导演台锚点长度一致的连续画面和可用音频，钉到生成开头并在输出中裁掉。 |
| RC-010 | 出点 MotionContext | 从 O 后读取连续画面和可用音频，放进额外生成的隐藏尾窗；采样后从可见成片中完整裁掉，不能复制后段开头或造成倒跳；非 H3 latent 相位边界必须保留条件锚点并跳过不安全的 latent 硬写入。 |
| RC-011 | 自动写回 | 生成完成后保存一条合并 AV 成片，并把其输出引用写回当前粗剪工程；生成期间若工程有新编辑，只合并生成片段而不回滚整份工程；节点中的成片播放器继续使用原生视频控件。 |
| RC-012 | 工程跟随工作流保存 | 粗剪工程作为版本化 JSON 存在导演台隐藏控件中；移动播放头或片段不得刷新整个导演台、打断输入光标。 |
| RC-013 | 本地路径安全 | 运行时只接受已登记素材库的相对路径或 ComfyUI/output 内的输出引用；所有路径在读取边界重新 canonicalize 并做 containment 校验。 |
| RC-014 | 可取消和可恢复 | 粗剪生成继续使用现有 ComfyUI 中断、进度、显存释放和分段保存机制。 |
| RC-015 | 粗剪导出 | 已提供结构化工程 JSON 与完整 V1/A1 MP4 导出；按工程帧率/画布处理视频、图片持续时间、空白区、内嵌音频和独立音轨。合成播放头预览与 OTIO 仍属后续。 |
| AI-001 | 智能助手按能力路由 | 只允许选择受信任能力：提示词、文生图、图片编辑、多参考合成、视频生成、视频桥接、时间轴插入。 |
| AI-002 | LLM 只产生计划 | LLM 输出小型受约束计划；确定性编译器选择预置工作流，禁止模型输出任意节点类、文件路径或安装指令。 |
| AI-003 | 路由考虑真实资源 | 路由必须读取本机已安装模型、显存预算、输入素材类型、许可策略和用户偏好；不能依据 LLM 自述判断。 |
| AI-004 | 图片模型分工 | Krea 2 与 Anima 只用作文生图候选；图片编辑固定复用用户现有的 MiniMax H3 图片编辑工作流，不路由到其他编辑模型。 |
| AI-005 | 模式级素材与提示词隔离 | 动作迁移、纯生成、视频续写分别保存自己的公共素材、镜头提示词、LLM 分段快照和分镜卡元数据；切换模式不得读取或覆盖其他模式数据。旧版单桶数据只迁移到首次打开时的当前模式。 |

## 非功能需求

- 不增加强制第三方 Python 或前端依赖。
- 不修改 ComfyUI 核心服务器和执行器。
- 不后台扫描整块磁盘；只扫描用户明确登记的文件夹，单库首版最多返回 10,000 个素材。
- 不把绝对素材路径写进可分享的时间轴片段；工程保存素材库 ID 与相对路径。
- 新增导演台控件必须追加在现有控件末尾，保证旧工作流的 `widgets_values` 位置不变。
- 所有实验能力必须有明确失败信息，不能静默退化为不同生成模式。

## 明确不承诺

- 单帧或 MotionContext 都能提高边界约束，但生成模型无法保证数学意义上的“完美无缝”。
- 第一阶段时间轴不是完整 NLE，不含复杂转场、速度曲线、字幕、关键帧特效和专业调音台。
- Krea 2、Anima、FLUX、MiniMax H3 的模型许可不同；“能本地运行”不等于所有场景都可商用。
