## 发布门槛

阶段 1 只有在以下条件全部满足后才从“实验”改为默认可见：

1. 现有导演台完整测试不回归。
2. Windows 本地素材路径和输出路径没有目录穿越。
3. 双端 MotionContext 不复制后段帧，输出帧数和音频采样数严格符合 I/O。
4. 关闭粗剪时动态子图与当前版本等价。
5. 至少三种运动、两种对白和一组静音素材通过人工切口检查。
