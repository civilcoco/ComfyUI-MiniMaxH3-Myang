# 自媒体发布素材（中文模板）

## 标题候选

- 我把 MiniMax H3 做成了可循环扩展的长视频节点
- H3 长视频接缝：多关键帧、音频续接与可选二采
- 开源 ComfyUI MiniMax H3 长视频工作流：从 8 秒扩展到长片

## 60～90 秒视频结构

1. 0～5 秒：同一接缝的“普通拼接 / Myang 锚定”对比。
2. 5～15 秒：展示问题——动作断裂、色彩漂移、音乐短暂重复。
3. 15～35 秒：展示核心——段间多关键帧、40Hz 音频时间线、同步裁剪。
4. 35～50 秒：展示可选功能——Turbo 调度与二采设置。
5. 50～65 秒：展示硬件、分辨率、步数、段长和实际耗时，不只放最好结果。
6. 65～80 秒：GitHub 安装、GPL-3.0、上游致谢和模型许可证提示。

## 推荐画面

- 16:9 横版：代码仓库介绍、完整工作流、长视频 A/B。
- 9:16 竖版：只展示一个接缝问题、一个参数变化、一个结果结论。
- 对比画面务必保持同 seed、同素材、同提示词、同编码设置。
- 画面角落标注：分辨率、步数、段长、上下文长度、显卡及是否二采。

## 发布前不要出现

- 本机绝对路径、Windows 用户名、API 服务配置、模型下载令牌。
- 私人素材文件名、聊天截图、未获授权的音乐或人物肖像。
- “完全原创”或“官方支持”等无法证明的表述。
- 未经验证的“无损”“完美接缝”“速度提升 N 倍”等绝对结论。
